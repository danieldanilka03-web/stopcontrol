# Встраиваемая прошивка телеметрического модуля павильона (STM32 + SIM800L)

Аппаратный комплекс автоматизированного мониторинга остановочных пунктов городского пассажирского транспорта в составе системы **StopControl**.

---

## 1. Назначение и функции устройства

Устройство представляет собой автономный промышленный контроллер на базе 32-битного микроконтроллера архитектуры **ARM Cortex-M4 (STM32F401RE)** или **Cortex-M3 (STM32F103C8T6)**, монтируемый в защищённый сервисный шкаф остановочного павильона.

### Основные аппаратные функции:
1. **Детекция механических ударов (ДТП / Вандализм):**
   - Датчик: цифровой 3-осевой акселерометр **InvenSense MPU-6050** по шине **I2C1**.
   - Аппаратное прерывание `EXTI4` при превышении ускорения свыше $4.0g$ (векторная сумма трёх осей $|G| = \sqrt{a_x^2 + a_y^2 + a_z^2}$).
2. **Контроль ночного освещения и целостности проводки:**
   - Датчик: аналоговый люксометр на фоторезисторе **GL5528** (вход 12-битного АЦП `ADC1_IN0`).
   - Контроль линии питания 220В через оптопару `PC817` на входе `PA1`.
   - Если линия включена, но освещенность $< 1$ лк — мгновенно фиксируется отказ светодиодных модулей или обрыв кабеля.
3. **Акустический контроль целостности ветрозащитного остекления:**
   - Высокочастотный компаратор звукового спектра разбития триплекса / закалённого стекла на входе `EXTI5`.
4. **Защита от несанкционированного доступа:**
   - Герконовый датчик вскрытия крышки распределительного шкафа на входе `EXTI13`.
5. **Беспроводная передача телеметрии:**
   - Сотовый модем **SIM800L GSM/GPRS** (UART2, 9600 бод).
   - Прямая отправка HTTP/HTTPS POST запросов с JSON-пакетом на облачный сервер StopControl (`/api/telemetry`).

## 2. Принципиальная схема подключения выводов (Pinout)

| Вывод STM32 | Периферия | Подключенное устройство | Назначение |
|---|---|---|---|
| **PA0** | ADC1_IN0 | Фоторезистор GL5528 | Измерение освещённости (0..5000 лк) |
| **PA1** | GPIO In | Оптопара PC817 (Сеть 220В) | Контроль наличия сетевого напряжения подсветки |
| **PA2** | USART2_TX | SIM800L RXD | Передача AT-команд в сотовый модем |
| **PA3** | USART2_RX | SIM800L TXD | Приём ответов модема (OK, +HTTPACTION) |
| **PA5** | GPIO Out | Зелёный светодиод SYS | Индикация тактовой работы контроллера (Heartbeat) |
| **PA6** | GPIO Out | Красный светодиод ALARM | Индикация активной тревоги (удар / сбой света) |
| **PA7** | GPIO Out | Синий светодиод GSM | Индикация передачи данных по GPRS |
| **PB0** | GPIO Out | SIM800L PWRKEY | Управление аппаратным включением/спящим режимом модема |
| **PB1** | GPIO Out | SIM800L RST | Аппаратный сброс модема при зависании |
| **PB6** | I2C1_SCL | MPU-6050 SCL | Тактовая линия шины I2C (100 кГц) |
| **PB7** | I2C1_SDA | MPU-6050 SDA | Линия данных шины I2C |
| **PC4** | EXTI4 | MPU-6050 INT | Прерывание Wake-On-Motion при ударе |
| **PC5** | EXTI5 | Датчик разбития стекла | Прерывание акустического компаратора |
| **PC13**| EXTI13 | Концевик шкафа | Контроль несанкционированного вскрытия |

## 3. Схема электропитания

```
 Городская сеть 220V
 (Включается ночью) ────► [ Блок питания 12V/2A ] ────► [ Контроллер заряда MP2617 ]
                                                              │
                                                              ▼
                                                   [ Буферная АКБ LiFePO4 3.2V 6000mAh ]
                                                              │
                                     ┌────────────────────────┴───────────────────────┐
                                     ▼                                                ▼
                         [ LDO 3.3V (STM32 + I2C) ]                      [ Step-Down 4.0V (SIM800L) ]
                         (Ток покоя: 12 мА)                              (Пиковый ток передачи: 2А)
```

- **Ночной режим:** Контроллер запитывается от городской сети уличного освещения и одновременно заряжает буферный аккумулятор.
- **Дневной режим:** Контроллер переходит в ультранизкопотребляющий режим `STOP Mode` с тактированием от LSE 32.768 кГц, просыпаясь по прерываниям сенсоров или таймеру раз в 30 минут.

## 4. Формат телеметрического пакета (HTTP POST /api/telemetry)

### Заголовки HTTP:
```http
POST /api/telemetry HTTP/1.1
Host: stopcontrol.vercel.app
Content-Type: application/json
X-Device-Key: dkey_vn_sennaya_78a1c9e2
Connection: close
```

### Тело запроса (JSON):
```json
{
  "apiKey": "dkey_vn_sennaya_78a1c9e2",
  "deviceId": "dev-stm32-01",
  "stopId": "stop-vn-1",
  "event": "impact",
  "details": "Кинетический удар 4.8g по металлоконструкции павильона",
  "gForce": 4.8,
  "lux": 120,
  "battery": 4.08
}
```

### Ответ сервера (200 OK):
```json
{
  "ok": true,
  "deviceId": "dev-stm32-01",
  "ticketCreated": true,
  "ticketId": "TICK-IoT-4821",
  "message": "Аварийный сигнал зарегистрирован, создан наряд TICK-IoT-4821",
  "deviceStatus": "alarm"
}
```

## 5. Демонстрация на защите дипломного проекта

Для наглядной демонстрации работы алгоритма на защите в веб-интерфейсе **StopControl** реализован **интерактивный программный эмулятор STM32**:
1. Откройте вкладку **«Устройства»** или нажмите кнопку **«Стенд IoT (STM32)»** в верхней панели сайта.
2. На панели эмулятора представлены физические сценарии (обрыв освещения, сильный удар, разбитие стекла).
3. При нажатии на кнопку стенд посылает **подлинный HTTP POST запрос** с кодом и параметрами, в точности совпадающими с кодом в файле `Core/Src/sim800l.c`.
4. Сервер мгновенно переводит статус остановки в «Аварийное», регистрирует наряд с меткой `«источник: датчик»` и отображает карточку на Канбан-доске диспетчера в реальном времени.
